# DaiBed 0.1.0

DaiBed — одиночная BedWars-игра с героями: четыре команды защищают свои
EnergyCore, собирают ресурсы, покупают снаряжение, строят мосты и выбивают
соперников в воид. Версия 0.1.0 является публичной single-player alpha.

## Запуск

1. Распакуйте архив в папку с правом записи.
2. Запустите `DaiBed.exe`.
3. Выберите основной матч 4x4x4x4 или отдельное обучение.

Игра сама создаёт `DaiBed.settings` при сохранении настроек. Установка среды
разработки и ручное создание конфигов не требуются.

## Управление

| Действие | Клавиша |
|---|---|
| Движение / прыжок | `WASD` / `Space` |
| Спринт / безопасный край | `Left Ctrl` / `Left Shift` |
| Быстрый мост | удерживать `C` и ПКМ |
| Атака / разрушение | ЛКМ / удерживать ЛКМ |
| Установка блока / предмет | ПКМ |
| Магазин и действие | `R` |
| Инвентарь / выбросить предмет | `E` / `Q` |
| Способности героя | `F`, `G`, `H` |
| Смена камеры | `F5` |
| Счёт матча | удерживать `Tab` |
| Меню | `Esc` |

Основные клавиши переназначаются в `Settings > Controls`.

## Системные требования

- Windows 10 или 11, x64.
- Четырёхъядерный процессор.
- 8 ГБ оперативной памяти.
- Видеокарта с поддержкой OpenGL 3.3, включая современные встроенные GPU.
- Около 100 МБ свободного места.

## Известные проблемы

Для release candidate нет известных критических crash, hang, softlock или
повреждения сохранений. Новые проблемы и crash-логи `crash_*.log` принимаются
в [GitHub Issues](https://github.com/dkyukeev/daibed/issues).

## Сборка из исходников

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Если raylib не установлен, CMake скачает raylib 5.0 через `FetchContent`.
Для полностью офлайн-сборки установите raylib заранее и используйте
`DAIBED_USE_SYSTEM_RAYLIB=ON`.

Developer build с automatch-инструментами:

```powershell
cmake -S . -B build-dev -G "Visual Studio 17 2022" -A x64 -DDAIBED_DEVELOPER_BUILD=ON
cmake --build build-dev --config Release
.\build-dev\Release\DaiBed.exe --automatch --runs 100 --speed 256 --minutes 20 --seed 10101
```

Сторонние лицензии перечислены в `THIRD_PARTY_LICENSES.md`.

## Модели героев

Исходники героев хранятся в `assets/heroes/<hero>/*.bbmodel`, а игра
загружает соседние `.glb` через raylib. Подробная схема экспорта и список
процедурных анимаций описаны в `assets/heroes/README.md`.

## Графика, звук и производительность

- Мир рисуется подготовленными мешами 16×16×16: генерируются только открытые
  грани, а после строительства перестраиваются только затронутые dirty-чанки.
- Направленный свет, атмосферный туман и emissive-пульсация работают через
  GLSL 3.30. Post-processing добавляет bloom, vignette, цветокоррекцию,
  damage flash и мягкую линзу снайперской оптики.
- Bloom сначала извлекается в уменьшенный буфер (25-50% по стороне в зависимости
  от качества эффектов), поэтому мягкие солнечные блики и свечение способностей
  остаются доступными и на слабой видеокарте.
- Встроенные звуковые тоны остаются fallback. Игра автоматически подхватывает
  внешние эффекты из `assets/audio/sfx` и потоковую OGG-музыку из
  `assets/audio/music`, если эти файлы добавлены в пакет.
- GLB с валидными skeletal-клипами проигрываются через raylib; текущая
  процедурная анимация остаётся fallback для моделей без костей или клипов.
- Фиксированный пул частиц ограничивает осколки, пыль, искры, дым и трейлы без
  неограниченного роста памяти.

В настройках доступны VSync, лимит FPS, три режима окна, render scale,
дальность прорисовки, качество теней и эффектов, bloom/post-processing,
раздельная громкость Master/Music/SFX/Ambient и режимы reduced flashes/camera
shake. Поддерживаются мышь/клавиатура и геймпад; dead zone, чувствительность и
кнопки геймпада сохраняются в `DaiBed.settings`.

Developer build: `F8` показывает FPS, draw calls, видимые чанки, число
треугольников и время последней перестройки мешей.
